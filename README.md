# 🌐 SaaS URL Shortener Frontend

A clean, modern, and responsive dashboard designed for users to create, manage, and analyze their shortened URLs.

## ✨ Key Capabilities
- **Effortless Shortening**: Convert long, messy URLs into clean, short links instantly.
- **Dashboard View**: Manage all your links in one place with creation dates and original URL previews.
- **Analytics Visualization**: Click "View Clicks" to see how your links are performing.
- **One-Click Copy**: Built-in clipboard support for quick sharing.

## 💻 Technical Highlights
- **Architecture**: Vanilla JavaScript with Async/Await (Fetch API).
- **Styling**: Modern CSS variables and responsive layout.
- **Integration**: RESTful API communication with Java Spring Boot + PostgreSQL backend.
- **Hosting**: Deployed on Vercel.

## 🚀 Getting Started
1. **Clone**: `git clone https://github.com/Kartik21407/url-shortener-frontend.git`
2. **Launch**: Simply open `index.html` in your browser.
